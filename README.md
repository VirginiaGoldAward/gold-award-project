# Gold Award Project Website

This is a static, multi-page informational site template designed for a Girl Scout Gold Award project submission.

## Pages

- Home (`index.html`)
- Project Overview (`project.html`)
- My Experience (`experience.html`)
- Implementation Guide (`implementation.html`)
- Feedback (`feedback.html`)

## Customize Before Publishing

- Replace all placeholder text with your project-specific details.
- Update progress status bars and impact metrics with real data.
- Set your own header image on the home page in `index.html`.
- Add supporting evidence artifacts (photos, charts, reports) as needed.

## Run Locally

Open any page in your browser, or use a local static server.

## Publish Free on GitHub Pages

1. Create a new GitHub repository.
2. Upload all files in this folder to the repository root.
3. In GitHub, open Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for deployment.
7. Your site will be live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.

## Feedback Collection Note

The current feedback form stores responses in each visitor's browser (`localStorage`) for demo purposes.
For real evidence collection, connect the form to a backend service (for example, Google Forms, Formspree, or a school-managed endpoint).
